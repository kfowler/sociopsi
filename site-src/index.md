# Socio-Psi

**A Psi-theoretic architecture for machine subjectivity.**

Socio-Psi is an autonomous software agent that fuses Dorner's Psi theory of motivated cognition with Jungian archetypal psychology. Nine homeostatic drives select from 68 actions; four Jungian archetypes generate parallel internal monologue that an Ego mediator integrates; and semantic memory with weighted recall enables consolidation during meditation. All creative output is generated by local LLMs. The agent runs as a native macOS process, treating battery level as vitality, CPU load as cognitive strain, and thermal state as fever.

## Design Principles

- **Minimal canned content.** Nearly every utterance is LLM-generated. If the model is down, the agent is silent.
- **Hardware as body.** Somatic state is measured from real sensors, not simulated.
- **Drives, not goals.** The agent acts to restore homeostatic balance, not to accomplish user-specified objectives.
- **Multiplicity of voice.** Internal monologue arises from competing archetypal perspectives, not a single personality.
